METHOD

Temporal priors meet appearance projection.

Given a source video I and an initial edit E, AnyPortal++ uses a frozen video prior to improve temporal coherence while task-adaptive projection preserves the appearance information that defines the edit.

At selected projection steps, the decoder 𝒟 maps the clean-latent prediction Xt to the RGB estimate Yt. The task operator fτ extracts components Ct, which are blended with references fτ,i(I,E) using the strength ατ,i and mask Mτ. Recombining the corrected components C^t gives the projected RGB estimate Y^t. For t>0, RPA uses the encoder ℰ statistics before and after projection to form the corrected latent X^t, carrying appearance corrections into subsequent denoising while compensating for VAE reconstruction discrepancies. At t=0, the projected RGB estimate is returned directly as the output.
